# Privacy Policy (Maxfiylik Siyosati) — Cleva

*Oxirgi yangilanish: 2026-yil 13-sentyabr*

Ushbu Maxfiylik Siyosati **Cleva** boti qanday ma'lumotlarni to'plashi, qanday ishlatishi va saqlashi haqida tushuntiradi.

## 1. Qanday ma'lumotlar saqlanadi?
Bot faqat o'z funksiyalarini bajarishi uchun zarur bo'lgan minimal ma'lumotlarni qayta ishlaydi:
- **Server sozlamalari:** Server ID, log kanali ID si, welcome kanali ID si va welcome xabari matni.
- **Moderatsiya ma'lumotlari:** Qoidabuzarliklarga berilgan ogohlantirishlar (Warns) — foydalanuvchi ID, sabab, sana va moderator ID si.
- **Log hodisalari:** O'chirilgan yoki tahrirlangan xabarlar, a'zolar kirish/chiqishi vaqtincha bot log kanaliga yo'naltiriladi, lekin bot tomonidan uchinchi shaxslarga berilmaydi yoki tashqi serverlarga sotilmaydi.

## 2. Ma'lumotlardan qanday foydalaniladi?
To'plangan ma'lumotlar faqat quyidagi maqsadlarda ishlatiladi:
- Server ma'murlari tomonidan sozlangan moderatsiya va log tizimini ta'minlash.
- Welcome xabarlarini avtomatik yuborish.

## 3. Ma'lumotlarni uchinchi shaxslarga berish
Bot hech qanday shaxsiy ma'lumotlarni sotmaydi, ijaraga bermaydi yoki uchinchi tomonlarga ulashmaydi.

## 4. Ma'lumotlarni o'chirish
Server ma'murlari botni serverdan chiqarib yuborish (kick/ban) orqali botdan foydalanishni to'xtatishi mumkin. Sozlamalar va warn ma'lumotlarini o'chirish bo'yicha bot ma'muriyatiga murojaat qilish mumkin.

## 5. Bog'lanish
Savollar yoki ma'lumotlarni tozalash bo'yicha murojaat uchun GitHub repozitoriyasi orqali bog'lanishingiz mumkin.
