# Terms of Service (Foydalanish Shartlari)

*Oxirgi yangilanish: 2026-yil 13-sentyabr*

Ushbu Discord boti ("Bot") dan foydalanish orqali siz quyidagi shartlarga rozilik bildirasiz.

## 1. Xizmatdan Foydalanish
- Bot serverlarni boshqarish, moderatsiya qilish, server loglarini yuritish va a'zolar uchun qulaylik yaratish maqsadida taqdim etiladi.
- Botdan Discord qoidalarini (Discord Terms of Service va Community Guidelines) buzish, spam tarqatish, boshqa foydalanuvchilarga zarar yetkazish yoki noqonuniy harakatlar uchun foydalanish qat'iyan taqiqlanadi.

## 2. Ruxsatlar va Moderatsiya
- Server ma'murlari botga berilgan ruxsatlar (masalan: Manage Roles, Timeout Members, Manage Messages) doirasida bot orqali amalga oshirilgan harakatlar uchun to'liq javobgardirlar.
- Bot dasturchilari server ma'murlarining botdan qanday foydalanishi yoki qanday moderatsiya qarorlari qabul qilishi uchun javobgar emas.

## 3. Xizmatning Kafolatlari
- Bot "bor holatida" (as-is) taqdim etiladi.
- Dasturchilar serverlar yoki hosting (Render.com) faoliyatidagi vaqtinchalik uzilishlar, kechikishlar yoki Discord API dagi cheklovlar uchun javobgar bo'lmaydi.

## 4. O'zgartirishlar
- Foydalanish shartlari istalgan vaqtda yangilanishi mumkin. Yangilanishlar ushbu sahifada e'lon qilinadi.

## 5. Bog'lanish
Agar savollar yoki takliflar bo'lsa, bot ma'muriyati yoki GitHub orqali murojaat qilishingiz mumkin.
